# 👋 Hi, I'm a Software Engineer!

## 💫 About Me

I'm a Software Engineer and a recent Software Engineering graduate from HITEC University with a **CGPA of 3.89/4.00**. I specialize in full-stack web development, particularly the MERN stack, and enjoy building scalable, secure, and user-focused applications.

My experience spans frontend and backend development, RESTful APIs, database design, cloud deployment, and AI integration. I work with technologies such as React.js, Node.js, Express.js, MongoDB, PostgreSQL, Python, Java, and AWS.

One of my key projects is **Payvault**, an AI-assisted escrow platform featuring LLM-powered dispute resolution using Llama-3, OCR-based information extraction using Google Cloud Vision, and real-time communication with Socket.IO.

🏆 **Achievement:** Secured 101st position nationwide with a 99.6 percentile in the National Skill Competency Test (NSCT) 2026, conducted by HEC in collaboration with P@SHA, among 33,000+ participants.

🌱 Currently interested in expanding my expertise in Artificial Intelligence, Backend Engineering, and Cloud Computing.

💡 I enjoy solving challenging problems, exploring new technologies, and building software that makes a real-world impact.
